# AMADEUS ESPAÑA 

## Descripción del proyecto
Este proyecto consiste en el desarrollo de una página web empresarial relacionada con Amadeus España, utilizando herramientas de desarrollo web.

## Tecnologías utilizadas
- HTML5
- CSS3
- JavaScript
- Excel

## Archivos del repositorio
- index.html
- styles.css
- script.js
- Base_de_datos_Amadeus_Travel.xlsx

## Objetivo
Desarrollar una plataforma web que represente una empresa del sector de viajes y vuelos, aplicando conocimientos de programación y diseño web.

## Autor
Proyecto académico.
